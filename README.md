# Codomax AI/ML Internship Project

This repository contains my completed Codomax AI/ML Internship work, including Python basics, data analysis, visualization, machine learning, and a student score prediction project.

## Project Overview

The main project predicts student scores based on study hours using Linear Regression.

### What I completed
- Python basics and programming practice.
- NumPy and Pandas for data handling.
- Matplotlib for data visualization.
- Linear Regression model for prediction.
- Model evaluation using MAE, MSE, RMSE, and R².
- A simple prediction app for user input.
- Final notebook and project documentation.

## Files Included
- `student_scores.csv` – dataset.
- `day11.py` – prediction app.
- `Final-Codomax-Student-Score-Project.ipynb` – final notebook.
- Screenshots and supporting files.

## Result
The project successfully demonstrates a complete beginner-friendly machine learning workflow from data loading to prediction.
